# 🐍 Estudos de Python - Fundamentos e POO

Este repositório contém meus cadernos de exercícios, desafios e anotações desenvolvidos durante as aulas de Python do curso do Prof. André Iacono (Udemy).

O objetivo deste espaço é registrar minha evolução prática com a linguagem e consolidar os conceitos de lógica e orientação a objetos.

---

## 🗂️ Estrutura dos Módulos

* **[Módulo 01 - Print e Comentários](./Modulo_01_Print_e_Comentarios.ipynb):** Conceitos iniciais, saídas no terminal e boas práticas de comentários.
* **[Módulo 02 - Fundamentos do Python](./Modulo_02_Fundamentos_do_Python.ipynb):** Variáveis, tipos de dados (`int`, `float`, `str`, `bool`), operadores e condicionais.
* **[Módulo 03 - Programação Orientada a Objetos (POO)](./Modulo_03_POO.ipynb):** Criação de classes, atributos (`self`), métodos, herança (`super()`) e encapsulamento de regras de negócio (Sistema de Escola).
* **[Exercícios Práticos](./Exercícios_de_Python.ipynb):** Resolução de desafios para fixação de conteúdo.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Linguagem:** Python 3
* **Ambiente de Desenvolvimento:** Google Colab / Jupyter Notebooks
